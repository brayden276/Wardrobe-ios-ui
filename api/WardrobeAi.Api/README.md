# Non-Production API

This project is not the production backend for Wardrobe AI.

Use `..\..\Wardrobe-ios-api` for the Railway-deployed API. The Ionic app in this repository should be built as the IPA client and configured with `UI_API_BASE_URL` pointing to the hosted `Wardrobe-ios-api` origin.

Do not deploy this `api/WardrobeAi.Api` project unless it is explicitly revived and reconciled with the production API contract.
